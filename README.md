# **COMID - Community Identification Module for Reddit Conversations**  

**COMID** is a Python toolkit for collecting and analyzing Reddit conversations. It offers powerful tools for building corpora, annotating topics, and performing temporal analysis of discussions in subreddit threads.  

---

## **Features**  

### What does COMID do?  

- Collects conversation threads from a subreddit.  
- Explores and processes collected data.  
- Generates a corpus based on the original content (O.C.) of Reddit threads.  
- Assists in annotating topics within pre-grouped conversation clusters.  
- Conducts temporal analysis of topics over time.  

### What does COMID not do?  
- COMID does **not** perform topic modeling. For that, we recommend using the [hSBM Topic Model](https://github.com/martingerlach/hSBM_Topicmodel).

## **Quick Start**  

### Installation  
Install COMID and download the `en_core_web_sm` model for **spaCy**:  

```bash
pip install comid
python -m spacy download en_core_web_sm
```

### Setting up Reddit Credentials  
To use COMID, configure your Reddit credentials. If you don’t have credentials yet, follow this [guide](https://www.geeksforgeeks.org/how-to-get-client_id-and-client_secret-for-python-reddit-api-registration/).  

```python
from comid.collector import RedditCollector
import datetime as dt

collector = RedditCollector()

# Configure Reddit credentials
collector.config_credentials(
    client_id="YOUR_CLIENT_ID",
    client_secret="YOUR_CLIENT_SECRET",
    password="YOUR_PASSWORD",
    username="YOUR_USERNAME"
)
```

### Collecting Data  
Specify the subreddit and date range for collecting thread IDs:  

```python
subreddit = 'digitalnomad'
start_dt = dt.datetime(2022, 1, 1)
end_dt = dt.datetime(2022, 1, 2)

# Download the original content (O.C.) thread IDs for the given subreddit and date range
collector.search_ids_by_datetime(subreddit, start_dt, end_dt)
```

Download all submissions, including the original content, comments, and replies:  

```python
collector.download_by_ids()
```

## **Generating and Reducing the Corpus**  

### Load JSON Files  
Load the downloaded submissions from JSON files:  

```python
from comid import Comid

cm = Comid()
files = ['dataset/submissions.json', 'dataset/comments.json']
cm.load_json_files(files=files)
```

### Generate the Corpus  
The corpus will include only the main submissions (no comments or replies). This process may take a few minutes for large datasets:  

```python
cm.generate_corpus()
print("Corpus size:", len(cm.corpus))
```

### Reduce the Corpus  
For efficient topic modeling, we recommend keeping the corpus size below **6,000 documents**. Reduce the corpus by filtering posts with fewer than 10 interactions (comments or replies):  

```python
cm.reduce_corpus(target_size=6000, optimize_num_interactions=False, min_num_interactions=10)
print("Corpus size:", len(cm.corpus), "Reduced corpus size:", len(cm.corpus_reduced))
```

---

## **Saving and Loading Data**  

### Save the Corpus  
Save the reduced corpus as a JSON file for use with hSBM:  

```python
cm.save_corpus(reduced=True)
```

### Save and Load COMID Instances  
You can save the current COMID state as a pickle file for future use:  

```python
cm.save("comid_saved_file.pickle")

# To reload a saved COMID instance:
from comid import Comid
cm = Comid.load("comid_saved_file.pickle")
```

## **Working with Clusters and Topics**  

### Load Cluster Data  
Load the CSV file containing clusters generated by the topic modeling step:  

```python
cluster_file = 'path_to_file/topsbm_level_1_clusters.csv'
cm.load_clusters_file(cluster_file)
cm.df_clusters.head()
```

### Print Cluster Samples  
Display random samples from a specific cluster:  

```python
cm.print_cluster_samples('Cluster 1', 3)
```

### Retrieve Flattened Conversation Text  
Get the full conversation as flattened text for a specific document ID:  

```python
doc_id = 'rtsodc'
text = cm.retrieve_conversation(doc_id)
print(text)
```

### Save a Cluster Summary  
Generate a CSV summary with columns for cluster ID, number of documents, percentage of total documents, and a topic label column for annotation:  

```python
cm.save_clusters_summary()
```

---

## **Building and Exploring Topics**  

### Build the Topics Data Frame  
Once you’ve annotated the clusters, build the topics data frame:  

```python
cm.build_topics("clusters_summary.csv")
cm.df_topics.head()
```

Alternatively, build the topics data frame based on a minimum percentage of documents per cluster (e.g., 7%):  

```python
cm.build_topics(min_percent=7)
```

### Group Topics by Time Period  
Group topics by days, weeks, months, or years for temporal analysis:  

```python
cm.group_by_period(period_type="m")
cm.df_periods.head()
```
