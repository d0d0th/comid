## Overview
The **Comid** module is a Python-based tool for processing, cleaning, and analyzing Reddit data. It supports 
functionalities such as loading data from JSON files, cleaning posts, generating and reducing corpora, grouping topics 
by time periods, and exporting summary information.

This module is designed to help data scientists and researchers manage and analyze large datasets of Reddit 
conversations with minimal effort.

---

## Initialization
```python
from comid import Comid

cm = Comid()
```

The `Comid` class initializes with several attributes for holding data such as loaded posts, corpus, reduced corpus, stopwords, clusters, topics, and periods.

## Attributes

The `Comid` class provides several attributes that store and organize data for easy analysis and manipulation of Reddit posts. These attributes include processed text corpora, clusters, topics, and periods, as well as the raw imported posts.

| **Attribute**   | **Description**                                                                                 |
|-----------------|-------------------------------------------------------------------------------------------------|
| `corpus`        | The full corpus dictionary containing tokens for each document (original post).                  |
| `corpus_reduced`| A reduced version of the corpus with fewer documents, useful when working with large corpora.    |
| `df_clusters`   | Tabular data of clusters generated from topic modeling.                                           |
| `df_periods`    | Tabular data with topic statistics grouped by predefined time periods.                           |
| `df_topics`     | Tabular data organizing submissions by topics.                                                   |
| `posts`         | A dictionary of all imported submissions, comments, and replies.                                 |
| `stopwords`     | A list of common stopwords used for filtering during text preprocessing.                         |

---

### corpus

The `corpus` attribute is a dictionary containing tokens for each **original content (O.C.)** submitted to a subreddit. Each O.C. is treated as a document in the corpus, where:  
- The **key** is the document ID (O.C. ID).  
- The **value** is a list of tokens (words) extracted from the document.  

#### Example:
```python
# Example of corpus dictionary
In [1]: print(cm.corpus)
Out[1]: 
{'rtsodc': ['expense', 'cad', 'digital', 'nomad', 'travel', 'across', 'canada'],
 's8bqb9': ['well', 'use', 'bmw', 'engine', 'usa'],
 's8bbkl': ['future', 'digital', 'world']}
 
In [2]: print(cm.corpus['s8bbkl'])
Out[2]: ['future', 'digital', 'world']
```

In the example above, the corpus contains three documents, and the document `s8bbkl` has the tokens *future*, *digital*, and *world*.

---

### corpus_reduced

The `corpus_reduced` attribute is a smaller version of the full `corpus`. It contains fewer documents but follows the same structure as the `corpus`. This attribute is generated by the `reduce_corpus()` method and is useful when working with large datasets that need to be downsized for more efficient analysis.

### df_periods

The `df_periods` attribute is a **Pandas DataFrame** containing topic statistics grouped by predefined time periods. It provides insights into the activity and popularity of topics over time.

| **Column**   | **Description**                                                                                  |
|--------------|--------------------------------------------------------------------------------------------------|
| `year`       | The year of the submission.                                                                      |
| `month`      | The month of the submission (only exists if topics are grouped by months or days).               |
| `week`       | The week of the year for the submission (only exists if topics are grouped by weeks).            |
| `day`        | The day of the submission (only exists if topics are grouped by days).                           |
| `topic`      | The label of the topic.                                                                          |
| `new_threads`| The number of new threads (O.C.) for the topic in the given time period.                         |
| `replies`    | The number of comments and replies for the topic in the given time period.                       |

#### Example:
```python
# Example of df_periods grouped by months
In [1]: cm.df_periods.head()
Out[1]:

1  2015    01    Pets           29       40
2  2015    01  Dreams           45       66
3  2015    02  Health           34       52
4  2015    02   Money           29       48
```

### df_topics

The `df_topics` attribute is a **Pandas DataFrame** that organizes submissions by topics, providing details about each submission.  

| **Column**     | **Description**                                                                                     |
|----------------|-----------------------------------------------------------------------------------------------------|
| `id`           | The submission ID.                                                                                  |
| `topic`        | The topic label or cluster name if the topic is not annotated.                                       |
| `author_id`    | The author ID of the submission.                                                                    |
| `depth`        | The depth of the submission in a thread conversation (`0` for original content).                     |
| `parent_id`    | The ID of the parent submission (if the submission is a comment or reply).                           |
| `created_at`   | The submission creation date and time in the format `YYYY-MM-DD HH:MM:SS`.                          |
| `created_utc`  | The submission creation date and time as a Unix timestamp.                                           |
| `fulltext`     | The full text of the submission.                                                                    |
| `oc`           | The ID of the original content (O.C.) that the submission belongs to.                               |
| `period`       | The time period in which the submission was grouped (if topics are grouped by periods).              |

#### Example:

### posts

The `posts` attribute is a dictionary of all Reddit submissions. A submission can be an **original content (O.C.)**, a **comment**, or a **reply**. Each submission is represented as a dictionary with various fields.  

| **Key**  | **Description**                                                                                         |
|----------|---------------------------------------------------------------------------------------------------------|
| `key`    | The submission ID.                                                                                      |
| `value`  | A dynamic dictionary containing all fields imported from the submission (e.g., author, creation time).   |

#### Example:
```python
# Example of posts dictionary
In [1]: len(cm.posts)
Out[1]: 601937

In [2]: cm.posts['s8bbkl']
Out[2]: 
{'author': 'guideinfoways',
 'author_id': 'ufkln',
 'created': 1642656725.0,
 'id': 's8bbkl',
 'title': 'What is the future of the digital world?',
 'full_text': 'What is the future of the digital world?',
 'replies': []}
```

## Methods

### load_json_files
`load_json_files(files=None, folder=None)`
Load JSON files containing Reddit posts into the `Comid` object.

**Parameters:**
- `files` (list, optional): List of file paths to load.  
- `folder` (str, optional): Path to a folder containing multiple JSON files.  

**Raises:**  
- `Exception`: If neither `files` nor `folder` is provided, or if both are provided.

---

### clean_data
`clean_data(remove_no_content=True, remove_no_author=True, keywords=[], boundary_keywords=False)`
Clean the data by removing posts that match specific criteria.

**Parameters:**  
- `remove_no_content` (bool): Remove posts without meaningful content.  
- `remove_no_author` (bool): Remove posts with no author information.  
- `keywords` (list): List of keywords to filter posts.  
- `boundary_keywords` (bool): Only remove posts with exact keyword matches if True.

---

### generate_corpus
`generate_corpus(use_lemmas=True, include_comments=False, model="en_core_web_sm")`
Generate a corpus from the loaded data by tokenizing, cleaning, and optionally lemmatizing the text.

**Parameters:**  
- `use_lemmas` (bool): Lemmatize tokens if True; otherwise, apply stemming.  
- `include_comments` (bool): Include comments in the corpus if True.
- `model` (str): The spacy model to use for tokenization. Default: `en_core_web_sm`.

---

### reduce_corpus
`reduce_corpus(target_size=6000, optimize_num_interactions=True, min_op_length=0, min_num_interactions=0)`
Reduce the corpus to a target size by filtering based on interaction count or post length.

**Parameters:**  
- `target_size` (int): Desired size of the reduced corpus.  
- `optimize_num_interactions` (bool): If True, optimize the number of interactions (comments and replies). If False, optimize the original post length (in tokens).  
- `min_op_length` (int): Minimum post length for filtering.  
- `min_num_interactions` (int): Minimum number of interactions for filtering.  

**Raises:**  
- `Exception`: If `target_size` is less than or equal to zero.

---

**Parameters:**  
- `save_path` (str): Directory where the file will be saved.  
- `file_name` (str): Name of the file. If not provided, a default name is generated.

### g_squared
`g_squared(f_xy, f_x, f_y, N)`
Calculates the G-squared statistical measure to evaluate word association strength in bigrams.

**Parameters:**
- `f_xy` (int): Frequency of the word pair (bigram).
- `f_x` (int): Frequency of the first word in the bigram.
- `f_y` (int): Frequency of the second word in the bigram.
- `N` (int): Total number of tokens in the dataset.

**Returns:**
- `float`: The G-squared statistic for the given word pair.

---

### npmi
`npmi(f_xy, f_x, f_y, N)`
Computes the Normalized Pointwise Mutual Information (NPMI) metric to score bigram associations based on their statistical significance.

**Parameters:**
- `f_xy` (int): Frequency of the word pair (bigram).
- `f_x` (int): Frequency of the first word in the bigram.
- `f_y` (int): Frequency of the second word in the bigram.
- `N` (int): Total number of tokens in the dataset.

**Returns:**
- `float`: NPMI value indicating the association strength between the two words.

---

### text2dict
`text2dict(text, keep_patterns={("ADJ", "NOUN"), ("NOUN", "NOUN"), ("PROPN", "PROPN")})`
Processes input text to extract tokens grouped by parts of speech (POS), and generates phrases by scoring bigrams using NPMI.

**Parameters**
- `text` (str): The input text to process.
- `keep_patterns` (set): POS tag patterns for bigrams to retain (default: `{("ADJ", "NOUN"), ("NOUN", "NOUN"), ("PROPN", "PROPN")}`).

**Returns:**
  - `dict`: A dictionary with the following structure:
  - POS groups: Keys represent POS tags (e.g., `"NOUN"`, `"VERB"`) and values are lists of unique tokens.
  - `PHRASE`: Contains meaningful bigrams combined into phrases (if applicable).

---

### text_tokenizer
`text_tokenizer(text, tags=["NOUN", "VERB", "ADJ", "PROPN"], min_size=3)`
Tokenizes and filters text based on specified POS tags and minimum token size.

**Parameters:**
- `text` (str): The text to tokenize.
- `tags` (list): POS tags to retain (default: `["NOUN", "VERB", "ADJ", "PROPN"]`).
- `min_size` (int): Minimum size of tokens to include (default: `3`).

**Returns:**
- **`list`**: A cleaned list of processed tokens.

### print_cluster_samples
`print_cluster_samples(cluster, n_samples=10, max_depth=0)`

Prints random samples from a specified cluster.

**Parameters:**
- `cluster` (str): The name of the cluster to analyze.  
- `n_samples` (int): The number of random samples to print. Default is 10.  
- `max_depth` (int): The maximum depth of replies to retrieve for each sample. If set to 0, only the original post (OC) will be retrieved. Default is 0.

**Returns:**  
- `None`

**Functionality:**  
This method selects a specified number of random samples from a given cluster and prints each sample’s conversation. The maximum depth of replies can be controlled through the `max_depth` parameter.

**Example Usage:**
```python
cm.print_cluster_samples(cluster="Cluster 1", n_samples=5, max_depth=2)
```

### save_clusters_summary
`save_clusters_summary(save_path="", file_name="")`

Saves a summary of cluster statistics as a CSV file.

**Parameters:**
- `save_path` (str): The directory where the file will be saved. Defaults to the current directory.  
- `file_name` (str): The name of the file. If not provided, a default name is generated in the format `clusters_summary_<timestamp>.csv`.

**Returns:**  
- `None`

**Functionality:**  
This method generates a CSV summary of clusters, including the following information for each cluster:  
- Cluster name  
- Number of documents in the cluster (`Num Docs`)  
- Percentage of documents in the cluster compared to the total (`Percent`)  
- Topic (initially left empty)  

The summary is saved as a CSV file in the specified directory or the current directory if no path is provided.

**Example Usage:**
```python
cm.save_clusters_summary(save_path="path/to/save", file_name="clusters_summary.csv")
```

**Sample Output (CSV):**
```
Cluster,Num Docs,Percent,Topic
cluster_1,150,15.0,
cluster_2,300,30.0,
cluster_3,550,55.0,
```

### build_topics
`build_topics(topics_file=None, min_percent=10)`

Creates a **topics conversation DataFrame** from the loaded data.

**Parameters:**  
- `topics_file` (str, optional): Path to a CSV file containing topic annotations. If provided, only the annotated topics from the file are considered.  
- `min_percent` (int): Minimum percentage of documents in a cluster to consider it as a topic. This parameter is ignored if `topics_file` is provided.  

**Returns:**  
- `None`

**Functionality:**  
- If `topics_file` is provided, it reads topic annotations from the CSV file and maps them to clusters.  
- If `topics_file` is not provided, it calculates the percentage of documents in each cluster and considers clusters with a percentage higher than or equal to `min_percent` as topics.  
- The method builds a **DataFrame** (`df_topics`) containing detailed information about the topics, including post content, author, timestamps, and replies.

**Example Usage:**  
```python
cm.build_topics(topics_file="path/to/topics.csv")
```

**Sample Output (DataFrame):**

| 67890 | health   | user456   | 1     | 12345     | 2025-02-01 14:05 | 1675298700  | Reply content.   | 12345|

### group_by_period
`group_by_period(period_type="m")`
Groups topics by a specified time period and updates the `df_topics` and `df_periods` DataFrames.

---

**Parameters:**  
- `period_type` (str): The time period for grouping topics. Accepted values are:  
  - `'d'` for daily grouping (e.g., `'2025-02-09'`)  
  - `'w'` for weekly grouping (e.g., `'2025-06'`)  
  - `'m'` for monthly grouping (e.g., `'2025-02'`)  
  - `'y'` for yearly grouping (e.g., `'2025'`)  

---

**Returns:**  
- `None`

**Raises:**  
- `Exception`: If the `period_type` is not one of the accepted values (`'d'`, `'w'`, `'m'`, `'y'`).

---

**Functionality:**  
- Updates the `df_topics` DataFrame by adding a new column called `period`, which contains the formatted period labels based on the specified `period_type`.  
- Generates the `df_periods` DataFrame to store aggregated data for each time period, including the number of new threads and replies for each topic.  
- Builds indices for words, topics, and periods, which are used for further analysis.  
- Supports multiple levels of time grouping (daily, weekly, monthly, and yearly).  

---

**DataFrames Generated:**  
- `df_topics`: Updated with a new `period` column and tokenized text for each entry.  
- `df_periods`: Contains aggregated statistics for each period, such as:  
  - **New Threads:** Number of new threads for the topic in the given period.  
  - **Replies:** Number of replies for the topic in the given period.  

**Example Usage:**  
```python
cm.group_by_period(period_type="m")  # Group topics by month
```

**Sample Output (`df_periods`):**  

| period   | year | month | topic   | new_threads | replies |  
|----------|------|-------|---------|-------------|---------|  
| 2025-02  | 2025 | 02    | tech    | 12          | 45      |  
| 2025-02  | 2025 | 02    | health  | 8           | 30      |  
| 2025-03  | 2025 | 03    | finance | 20          | 70      |

### retrieve_conversation
`retrieve_conversation(doc_id, max_depth=99999, include_author_id=True, include_created=True, level=0)`

Recursively retrieves a thread conversation as flattened text.

---

**Parameters:**  
- `doc_id` (str): The ID of the post.  
- `max_depth` (int): Maximum depth of replies to retrieve. Default is `99999`. If `0`, only the original post is retrieved.  
- `include_author_id` (bool): Whether to include the author's ID in the output. Default is `True`.  
- `include_created` (bool): Whether to include the post's creation time in the output. Default is `True`.  
- `level` (int): The current depth level of the conversation. Default is `0`.  

**Returns:**  
- `str`: The flattened text representation of the conversation.  

**Functionality:**  
- Recursively retrieves a thread conversation up to the specified depth and flattens it into a single string.  
- Supports optional inclusion of the post's author ID and creation time for context.  
- Skips posts marked as `"[removed]"` or `"[deleted]"`.  

**Example Usage:**  
```python
conversation_text = comid.retrieve_conversation(doc_id="abc123", max_depth=2)
print(conversation_text)
```

## Usage Example

```python
from comid import Comid

# Initialize Comid instance
cm = Comid()

# Load Reddit data from JSON files in a folder
cm.load_json_files(folder="path/to/json/folder")

# Clean the data by removing posts without content and authors
cm.clean_data(remove_no_content=True, remove_no_author=True)

# Generate the corpus with lemmatization
cm.generate_corpus(use_lemmas=True)

# Save the generated corpus as a JSON file
cm.save_corpus(save_path="path/to/save", file_name="corpus.json")

# Load the saved corpus
cm.load_corpus("path/to/save/corpus.json")
```
