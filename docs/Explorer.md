# Explorer Module Documentation  

The `Explorer` module provides tools to analyze and explore datasets containing posts and comments. It efficiently calculates thread-level and author-level statistics, identifies replies within threads, and generates activity summaries over specified time intervals.

## Statistical Output

The `Explorer` class generates several statistical objects that can be analyzed and exported as files for deeper 
insights:  

- **Thread Statistics (`threads_stats`)**  
  A dictionary where each key is a thread ID, and the corresponding value is a nested dictionary with detailed statistics for that thread:  
    - **Number of Posts (`number_of_posts`):** Total number of posts in the thread.  
    - **Author Count (`author_count`):** Number of unique authors who contributed to the thread.  
    - **Posts Without Author Count (`posts_without_author_count`):** Number of posts without an associated author.  

- **Author Statistics (`authors_stats`)**  
  A dictionary where each key is an author ID, and the value is a list of tuples representing the author’s posts. Each tuple contains:  
    - **OC ID:** The ID of the original content (OC) thread the post belongs to.  
    - **Post ID:** The unique ID of the post.  

- **Thread Replies (`thread_replies`)**  
  A dictionary where each key is a thread ID, and the value is a list of comment IDs that represent replies within that thread.  

-  **Thread Interval Activity (`thread_activity`)**  
  A dictionary that tracks thread activity over specified periods, summarizing post activity within each time frame.  

- **Thread Interval Activity DataFrame (`df_interval_activity`)**  
  A Pandas DataFrame summarizing interval-based thread activity. Each row corresponds to a thread, with columns representing activity counts for different time periods (days, weeks, months, etc.).



## Initialization

When initialized, the `Explorer` receives the post object generated by Comid as a parameter and automatically generates 
all the statistical objects.

### `Explorer(posts)`

**Parameters:**  
- `posts` (`dict`): A dictionary containing post data with post IDs as keys.

**Attributes:**  
- `posts`: The dataset containing post data.  
- `threads_stats`: Dictionary storing thread statistics.  
- `authors_stats`: Dictionary storing author statistics.  
- `thread_replies`: Dictionary tracking replies for each thread.  
- `_thread_authors`: Internal dictionary tracking authors per thread.  
- `df_interval_activity`: Pandas DataFrame for interval-based thread activity.  
- `thread_activity`: Dictionary tracking activity based on periods.


```python
# Example of initializing the Explorer with Comid data

from comid.explorer import Explorer
from comid import Comid

# Load Comid data
cm = Comid()
files = ['submissions_1725696945.json', 'comments_1725696945.json']
cm.load_json_files(files=files)

# Initialize the Explorer with the loaded posts from Comid
explorer = Explorer(cm.posts)
```

## Methods

### data_summary
`data_summary()`

**Description:**  
Prints a summary of the dataset. The summary includes:  
- Number of original content (OC) posts  
- Number of comments and replies  
- Number of posts without content  
- Number of posts without an author  

**Example Usage:**  
```python
explorer.data_summary()
```

---

### thread_interval_activity
`thread_interval_activity(period_type)`

**Description:**  
Calculates and stores interval-based thread activity.

**Parameters:**  
- `period_type` (`str`): The time period for grouping posts. Available options:  
  - `'d'`: Days  
  - `'w'`: Weeks  
  - `'f'`: Fortnights  
  - `'m'`: Months  
  - `'q'`: Quarters  
  - `'y'`: Years  

**Example Usage:**  
```python
explorer.thread_interval_activity('m')
```

---

### export_data
`export_data(save_path="")`

**Description:**  
Exports thread statistics, author statistics, and interval activity to files.

**Parameters:**  
- `save_path` (`str`, optional): The directory to save the exported files. Defaults to the current directory.

**Exports:**  
- JSON files for thread statistics, author statistics, thread replies, and thread activity.  
- CSV file for interval-based activity.

**Example Usage:**  
```python
explorer.export_data("/path/to/save/")
```
#### Private Utility Methods

- `_proc_thread(post_id, oc)`:  
  Processes thread statistics for a given post and updates the statistics recursively for each post and its replies.

- `_proc_interval(post_id, oc_id, data, row_index, posts, periods_dict, period_type)`  
  Recursively processes and updates interval-based thread activity.

- `_dump_json(obj, file_name, save_path)  
  Saves a Python object as a JSON file.

- `_dump_dataframe(df, file_name, save_path)`  
  Saves a pandas DataFrame as a CSV file.

- `_period_key(timestamp, period_type)`  
  Retrieves the period group label given a timestamp and period type.

## Usage Example

```python
from comid import Comid
from comid.explorer import Explorer

# Step 1: Load Comid and JSON files
cm = Comid()
files = ['submissions.json', 'comments.json']
cm.load_json_files(files=files)

# Step 2: Initialize Explorer with loaded posts
explorer = Explorer(cm.posts)

# Step 3: Display a summary of the dataset
explorer.data_summary()

# Step 4: Access and print different statistical objects

# Author statistics dictionary (author contributions and posts)
print("Author Statistics:", explorer.authors_stats)

# Thread replies dictionary (list of comment IDs for each thread)
print("Thread Replies:", explorer.thread_replies)

# Thread statistics dictionary (detailed stats for each thread)
print("Thread Statistics:", explorer.threads_stats)

# Thread interval activity dictionary (activity grouped by time periods)
print("Thread Interval Activity:", explorer.thread_activity)

# Pandas DataFrame for thread interval activity
print("Thread Interval Activity DataFrame:")
print(explorer.df_interval_activity)

# Step 5: Export all statistical data to files
explorer.export_data()
```
